# Changelog

## 1.0.0

First public release.

- Live media pill and expanded player with output device picker
- Volume, brightness and media key HUDs in the notch
- AirPods / Beats / JBL connect cards with battery, Touch ID animation, low battery and charging cards, screen recording indicator
- Notification mirroring and Focus indicators
- Full-screen aware: only system state changes show over full-screen apps
- JavaScript plugin system with permissions, optional local HTTP API
- Settings window: language, Dock / menu bar icon, timings, events, permissions, health checks
